# Changelog

Tutti i cambiamenti di **QRArchive** saranno documentati in questo file.

---

## Versione [1.01] - 2026-08-28

### Nuove funzionalità
- **Download diretto dalla dashboard:** Possibilità di scaricare i QR code salvati direttamente dall'elenco della dashboard.
- **Eliminazione QR:** Opzione per cancellare un QR code e il relativo file direttamente dalla dashboard.
- **Supporto URL:** Nuova modalità per generare QR code associati a un link/URL web, oltre ai normali file.

---

## Versione [1.00] - 2026-08-27

- **Autenticazione utente:**
  - Registrazione account.
  - Login e Logout.
- **Gestione File & QR:**
  - Caricamento di singoli file (immagini, documenti e altri formati).
  - Generazione automatica del QR Code univoco collegato al file caricato.
  - Download del codice QR appena generato.
- **Dashboard Personale:**
  - Visualizzazione di tutti i QR code creati.
  - Anteprima dei file caricati associati ai codici.
